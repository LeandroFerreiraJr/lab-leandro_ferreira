1. Introdução ao HTML

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto).

É uma linguagem utilizada para estruturar o conteúdo de páginas da internet. Por meio dela podemos organizar textos, imagens, links, tabelas, formulários e outros elementos.

O HTML trabalha com elementos identificados por tags, que indicam ao navegador como o conteúdo deve ser interpretado.

Exemplo:

<h1>Minha primeira página</h1>
<p>Este é um parágrafo em HTML.</p>

2. Estrutura Básica de um Documento HTML

Todo documento HTML possui uma estrutura básica que informa ao navegador como interpretar a página.

Os principais elementos são:

  • <!DOCTYPE html>: informa que o documento utiliza HTML5.
  • <html>: elemento raiz do documento.
  • <head>: contém informações e configurações da página.
  • <title>: define o título da aba do navegador.
  • <body>: contém o conteúdo visível da página.

Exemplo completo:

<!DOCTYPE html>
<html lang="pt-BR">

<head>
    <meta charset="UTF-8">
    <title>Minha Página</title>
</head>

<body>

    <h1>Olá, mundo!</h1>
    <p>Minha primeira página HTML.</p>

</body>

</html>

3. Tags Básicas

As tags são utilizadas para definir os elementos que compõem uma página HTML.

  • <h1> até <h6>: criam títulos e subtítulos.
  • <p>: cria parágrafos.
  • <br>: insere uma quebra de linha.
  • <hr>: representa uma separação temática.
  • <strong>: indica conteúdo de grande importância.
  • <em>: indica ênfase no texto.
  • <div>: cria um contêiner genérico.
  • <span>: agrupa conteúdo em linha.

Exemplo:

<h1>Título Principal</h1>
<h2>Subtítulo</h2>

<p>Este é um parágrafo.</p>

<strong>Texto importante</strong>

<em>Texto com ênfase</em>

<br>

<hr>

4. Formatação de Textos

O HTML oferece elementos que permitem destacar partes específicas de um texto.

  • <b>: chama atenção visual para o texto.
  • <i>: apresenta texto em itálico.
  • <u>: apresenta texto sublinhado.
  • <mark>: destaca um trecho.
  • <del>: representa texto removido.
  • <small>: apresenta texto menor.
  • <sub>: apresenta texto subscrito.
  • <sup>: apresenta texto sobrescrito.

Exemplo:

<p><b>Texto em negrito</b></p>

<p><i>Texto em itálico</i></p>

<p><u>Texto sublinhado</u></p>

<p><mark>Texto destacado</mark></p>

<p>H<sub>2</sub>O</p>

<p>2<sup>3</sup> = 8</p>

5. Listas Ordenadas e Não Ordenadas

As listas permitem organizar informações em tópicos. Existem dois tipos principais:

Lista não ordenada (<ul>)

Utiliza marcadores para organizar os itens.

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Resultado:

  • HTML
  • CSS
  • JavaScript

Lista ordenada (<ol>)

Utiliza números ou outros marcadores ordenados.

<ol>
    <li>Planejamento</li>
    <li>Desenvolvimento</li>
    <li>Publicação</li>
</ol>

Resultado:

  1. Planejamento
  2. Desenvolvimento
  3. Publicação

Também podemos criar listas aninhadas, colocando uma lista dentro de outra.

6. Links e Imagens

Links (<a>)

A tag <a> permite criar links para outras páginas, sites externos ou seções do próprio documento.

Exemplo de link interno:

<a href="index.html">
    Voltar ao Início
</a>

Exemplo de link externo:

<a href="https://www.google.com"
   target="_blank"
   rel="noopener noreferrer">
    Acessar Google
</a>

Imagens (<img>)

A tag <img> permite inserir imagens em uma página. Os principais atributos são:

  • src: indica o caminho da imagem.
  • alt: fornece uma descrição alternativa.
  • width: define a largura.
  • height: define a altura.

Exemplo:

<img src="imagem.jpg"
     alt="Descrição da imagem"
     width="300">

7. Tabelas HTML

As tabelas são utilizadas para organizar dados em linhas e colunas.

Principais tags:

  • <table>: cria a tabela.
  • <tr>: cria uma linha.
  • <th>: cria uma célula de cabeçalho.
  • <td>: cria uma célula de dados.
  • <caption>: define o título da tabela.

Exemplo:

<table border="1">

    <tr>
        <th>Nome</th>
        <th>Idade</th>
    </tr>

    <tr>
        <td>Leandro</td>
        <td>25</td>
    </tr>

</table>

Resultado:

Nome Idade
Leandro 25

8. Formulários HTML

Os formulários permitem coletar informações fornecidas pelos usuários.

Principais elementos:

  • <form>: define o formulário.
  • <label>: identifica um campo.
  • <input>: cria campos de entrada.
  • <textarea>: cria uma área de texto.
  • <button>: cria um botão.
  • <select>: cria uma lista de opções.

Exemplo:

<form>

    <label for="nome">Nome:</label>

    <input type="text" id="nome">

    <br><br>

    <label for="email">E-mail:</label>

    <input type="email" id="email">

    <br><br>

    <button type="submit">
        Enviar
    </button>

</form>

9. Elementos Semânticos

Os elementos semânticos ajudam a organizar o conteúdo de uma página de maneira mais clara e significativa.

  • <header>: representa o cabeçalho.
  • <nav>: representa uma área de navegação.
  • <main>: representa o conteúdo principal.
  • <section>: representa uma seção temática.
  • <article>: representa um conteúdo independente.
  • <aside>: representa conteúdo complementar.
  • <footer>: representa o rodapé.

Exemplo:

<header>
    Cabeçalho do site
</header>

<nav>
    Menu de navegação
</nav>

<main>

    <section>
        Conteúdo principal
    </section>

</main>

<footer>
    Rodapé do site
</footer>
